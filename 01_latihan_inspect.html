Modul 01: Fondasi Pertama

Kekuatan Inspect Element (DevTools)

Selamat datang di dunia Web Security! Di sini Anda akan membuktikan sendiri kenapa seorang web tester tidak boleh percaya pada tampilan visual web.

💡 Kunci Utama: Semua yang tampil di browser Anda (HTML, CSS, JavaScript) berada 100% di bawah kendali Anda. Tekan F12 pada keyboard Anda untuk membuka Developer Tools (Inspect) sekarang juga!

🎯 Misi 1: Tombol yang Dinonaktifkan
Tingkat: Sangat Mudah

Di bawah ini ada tombol klaim hadiah. Developer memberi atribut disabled sehingga tombol berwarna abu-abu dan tidak bisa diklik oleh user biasa.

🔍 Trik Inspect: Klik kanan pada tombol abu-abu di bawah $\rightarrow$ pilih Inspect. Di tab Elements, temukan kata disabled="" lalu hapus kata tersebut dengan tombol Delete / Backspace. Setelah itu klik tombolnya!
🎯 Misi 2: Mengintip Rahasia di Balik Bintang (Password)
Tingkat: Mudah

Ada password admin rahasia yang tersimpan di kolom input di bawah ini, tapi browser menutupinya dengan bulatan/bintang hitam (••••••••).

🔍 Trik Inspect: Klik kanan pada input password $\rightarrow$ pilih Inspect. Cari atribut type="password", lalu klik dua kali dan ubah menjadi type="text"!
🎯 Misi 3: Bobol Harga Toko (Client-side Tampering)
Tingkat: Simulasi Nyata

Saldo dompet Anda hanya Rp 50.000. Anda ingin membeli Laptop Gaming ROG seharga Rp 25.000.000. Bisakah Anda membelinya?

🔍 Trik Inspect: Klik kanan tombol Beli Sekarang $\rightarrow$ pilih Inspect. Tepat di dekat tombol tersebut, ada input tersembunyi (hidden input): name="harga" value="25000000". Ubah value menjadi 10000 lalu klik tombol beli!
