DevTools 4-Tab Mastery Lab

Asah kemampuan eksploitasi web kamu di 4 tab paling vital: Elements, Console, Application, dan Network.

Tingkat Keberhasilan Lab: 0 / 4 Selesai (0%)
Tab Elements
Misi 1: Otorisasi Form & Hidden Privilege Escalation
Belum Selesai

Developer sistem proteksi membuat tombol "Upgrade ke Super Admin" terkunci mati dengan atribut disabled. Selain itu, ada parameter input rahasia bertipe hidden yang diam-diam mengirimkan identitas guest_trainee ke sistem.

💡 Cara Hack via Tab Elements
1. Klik kanan pada tombol abu-abu di bawah $\rightarrow$ pilih Inspect.
2. Di tab Elements, hapus kata disabled="" pada tag <button>.
3. Tepat di atas tombol itu, perhatikan tag:
<input type="hidden" id="elem-role" name="role_level" value="guest_trainee">.
4. Klik dua kali pada teks value="guest_trainee" dan ganti menjadi value="super_admin".
5. Klik tombol yang sekarang sudah aktif!
Status Akun Saat Ini: guest_trainee
Tab Console
Misi 2: Memory Tampering & Trigger Fungsi Rahasia
Belum Selesai

Aplikasi menyimpan status verifikasi lisensi di dalam objek JavaScript memori (variabel global). Juga terdapat fungsi darurat tersembunyi yang dibuat developer namun tidak dipasang di tombol mana pun di layar.

💡 Cara Hack via Tab Console
1. Buka DevTools (tekan F12) lalu klik tab Console.
2. Kamu punya 2 cara untuk membobol ini di Console:
* Opsi A (Manipulasi Objek): Ketik
window.vaultSecurity.isVerified = true lalu tekan Enter.
* Opsi B (Panggil Fungsi Rahasia): Ketik
window.emergencyBypassAccess() lalu tekan Enter.
3. Setelah itu, klik tombol "Verifikasi Lisensi Sistem" di bawah!
Target Objek JavaScript: window.vaultSecurity
Target Fungsi Rahasia: window.emergencyBypassAccess()
Tab Application
Misi 3: Privilege Escalation via Cookie / LocalStorage
Belum Selesai

Website ini mempercayai status sesi pengguna berdasarkan Cookie dan LocalStorage yang disimpan di komputermu. Secara default, kamu dicatat sebagai user biasa (guest). Manipulasi tiket pengenal tersebut langsung di storage browser!

💡 Cara Hack via Tab Application
1. Buka DevTools (F12) $\rightarrow$ klik tab Application (jika tidak terlihat, klik tanda panah ganda >>).
2. Di panel sebelah kiri, buka menu Storage $\rightarrow$ Cookies $\rightarrow$ klik alamat web kamu (misal: http://127.0.0.1:5500).
3. Temukan baris dengan nama auth_role yang nilainya guest.
4. Klik dua kali pada tulisan guest, ubah menjadi admin lalu tekan Enter.
(Alternatif: Di Local Storage, ubah kunci user_privilege dari free menjadi god_mode).
5. Kembali ke halaman ini dan klik tombol "Periksa Tiket Akses Saya"!
Storage yang Dimonitor:
• Cookie: auth_role (Ubah nilainya menjadi admin)
• LocalStorage: user_privilege (Ubah nilainya menjadi god_mode)
Tab Network
Misi 4: Information Disclosure (Mengintip Bocoran API JSON)
Belum Selesai

Saat kamu menekan tombol "Ambil Data Profil Publik", frontend melakukan request fetch() ke endpoint backend. Halaman web di layar hanya menampilkan nama dan foto saja. Namun, backend yang ceroboh membocorkan Secret Master PIN / Flag rahasia di dalam respon data mentah!

💡 Cara Hack via Tab Network
1. Buka DevTools (F12) $\rightarrow$ klik tab Network.
2. Pastikan filter tab Network diatur ke Fetch/XHR atau All.
3. Klik tombol "Ambil Data Profil Publik" di bawah.
4. Perhatikan di tab Network akan muncul baris request baru bernama: api_user_data.json.
5. Klik baris tersebut $\rightarrow$ buka tab Preview atau Response di panel kanan.
6. Temukan nilai admin_secret_pin atau leaked_flag yang tersembunyi.
7. Salin (copy) kodenya dan masukkan ke kolom input verifikasi di bawah!
